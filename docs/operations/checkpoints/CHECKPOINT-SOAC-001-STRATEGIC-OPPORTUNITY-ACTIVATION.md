## 1. PURPOSE

این Checkpoint به‌عنوان مرجع راهبردی مستقل برای تبدیل ظرفیت‌های موجود و آینده به فرصت، ارزش و اثرگذاری عملیاتی ثبت می‌شود.

این سند جایگزین Checkpointهای عملیاتی نیست و هیچ Checkpoint قبلی را حذف، ابطال یا بازنویسی نمی‌کند.

---

## 2. NON-REGRESSION BOUNDARY

SOAC-001 یک لایه راهبردی است و نباید باعث بازگشت به Build، ILR یا Phaseهای قدیمی شود.

آخرین وضعیت عملیاتی معتبر همچنان مرجع اجرای فنی است.

هر اقدام جدید باید ابتدا وضعیت فعلی Repository و آخرین Operational Checkpoint را بررسی کند.

---

## 3. STRATEGIC SHIFT

حرکت SKOS از:

Knowledge Management

به:

Knowledge → Capability → Opportunity → Value

هدف فقط ذخیره یا ارائه دانش نیست؛ هدف، کشف و فعال‌سازی ظرفیت‌هایی است که می‌توانند به فرصت واقعی تبدیل شوند.

## 4. THREE OPPORTUNITY MINES

### Mine 01 — Existing Intellectual Assets

کتاب‌ها، مقالات، ایده‌ها، چارچوب‌ها، فایل‌ها، مطالعات و دانش انباشته‌شده.

### Mine 02 — Hidden Assets & Capacities

مهارت‌های استفاده‌نشده، شبکه‌های پراکنده، اطلاعات پنهان، پروژه‌های متوقف‌شده، ظرفیت‌های بلااستفاده، نیازهای پاسخ‌داده‌نشده و منابعی که هنوز به بازار متصل نشده‌اند.

### Mine 03 — Engineered Future Mines

ظرفیت‌هایی که از ترکیب هوشمندانه دانش، افراد، منابع، فناوری و نیازها ایجاد می‌شوند.

### Golden Principle

Opportunity Is Not Always Found. Sometimes It Is Engineered.

---

## 5. CORE OPPORTUNITY CYCLE

SCAN → MAP → CONNECT → DISCOVER → CREATE → VALIDATE → ACTIVATE → LEARN

### SCAN
مشاهده مستمر جهان، منابع، نیازها، فناوری‌ها، بازارها و تغییرات.

### MAP
ترسیم دارایی‌ها، ظرفیت‌ها، نیازها، بازیگران و منابع.

### CONNECT
کشف ارتباط میان دانش، افراد، منابع، نیازها و فرصت‌ها.

### DISCOVER
یافتن راه‌حل‌ها، فناوری‌ها، بازارها، تأمین‌کنندگان، متخصصان و فرصت‌های پنهان.

### CREATE
ساختن ترکیب یا پیکربندی جدید برای ایجاد ارزش.

### VALIDATE
آزمون سریع فرضیه با شواهد واقعی.

### ACTIVATE
تبدیل فرصت معتبر به محصول، خدمت، پروژه، همکاری یا قرارداد.

### LEARN
ثبت نتیجه، شواهد، الگوها و آموخته‌ها برای چرخه بعدی.

## 11. GOPM — GLOBAL OPPORTUNITY & PUZZLE METHOD

GOPM به‌عنوان روش مادر برای حل مسئله، کشف فرصت و طراحی پیکربندی‌های جدید تعریف می‌شود:

SEE → SCOPE → DECOMPOSE → KNOW → CONNECT → DISCOVER → COMPOSE → SIMULATE → OPTIMIZE → EXECUTE → VERIFY → EVOLVE

اصل:

Never solve a problem directly.

ابتدا باید مسئله دیده، محدوده‌بندی، قطعه‌بندی، شناخته و به شبکه روابط متصل شود؛ سپس گزینه‌های جهانی کشف، ترکیب، شبیه‌سازی، بهینه‌سازی و اجرا شوند.
